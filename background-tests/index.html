Seamless Background — 5 Options

5 ways to give your site a continuous, seam-free background. Open each demo, scroll through, see how the bg behaves. Section backgrounds are transparent in every demo — that's the whole trick.

~1-3 MBImage

A · One Long Vertical Image

Your original idea. One tall PNG/JPG stretched down the whole body.

→ Works but heavy & rigid
0 KBCSS only

B · CSS Gradient on Body

Pure CSS linear-gradient. No image. Scales infinitely. Easy to tweak.

→ Lightest, most flexible
~200-400 KB1 image

C · Fixed Viewport Image

One screen-sized image, locked via background-attachment: fixed. Content scrolls past it.

→ Premium cinematic feel
~1-10 KBTile

D · Seamless Tileable Pattern

Tiny image that repeats. Edges designed to align. Great for texture/grain.

→ Tiniest file, texture only
~2-5 KBGradient + texture

E · Gradient + Texture Hybrid

CSS gradient UNDER a tiny noise/grain layer. Best of B and D combined.

Option C

Fixed Viewport Image

One image, viewport-sized. background-attachment: fixed locks it in place while content scrolls past.

Scroll — Watch the BG

The background doesn't move. Content slides over a static image. Result: no seams ever, because there's nothing to seam against.

Tradeoffs

File Size

~200-400 KB. One screen worth.

Mobile Issue

iOS Safari ignores fixed attachment. Fallback: image scrolls normally.

Feel

Premium, almost cinematic. Apple uses this pattern.

Best For

Hero-driven sites where the bg is a vibe, not the focus. Less great if you want bg to "tell a story" as user scrolls.

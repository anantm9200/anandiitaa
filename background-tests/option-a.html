One Long Vertical Image

Your original plan. One huge PNG/JPG stretched down the whole body. Sections are transparent so the image shows through everywhere.

Scroll Down →

Notice no section boundaries. Bg flows top to bottom as one continuous image.

The Problem

If you add a new section, the image doesn't stretch — it either tiles (ugly seam) or runs out (background-color fallback shows). Try resizing window width too: aspect ratio may distort.

File Size

A 1440×4000 image at decent quality = 1-3 MB. Heavy on mobile.

Page Length Lock

Each page needs its own custom-length image.

Hard to Iterate

Want a color tweak? Re-export the whole image.

End of Image

If page grows past 4000px tall, background-color fallback kicks in below. Seam reappears.
